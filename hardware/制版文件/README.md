# 制版文件 | Fabrication Files

本目录存放排队状态监测器转接板的制版输出，用于打样下单与结构核对。

| 文件 | 内容 |
| --- | --- |
| `Gerber_PCB_排队状态监测器.zip` | 嘉立创下单用 Gerber 包（含钻孔、外形、丝印、阻焊） |
| `PCB_PCB1_2026-11-03.png` | 2D 布线预览（顶层 / 底层） |
| `3D_PCB1_2026-11-03.png` | 3D 渲染图，用于核对模块本体与挖空位置 |

## 板参数

- 尺寸：100 × 100 mm，2 层，板厚 1.6 mm
- 模块：STM32F103C8T6 最小系统板、ESP32（CH340）、DS3231、SD 卡模块（2×8 针）、E18-D80NK ×4、10 kΩ 上拉 ×4
- 固定挖空：矩形 9 × 4.5 mm + 圆 R11 mm，矩形下边为圆的弦

> 3D 渲染与 2D 预览仅为版图核对用，实际下单以 Gerber 包为准。
