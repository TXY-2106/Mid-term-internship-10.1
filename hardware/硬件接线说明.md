# 硬件接线说明

> STM32F103C8T6 / ESP32-WROOM-32 / E18-D80NK ×4 / DS3231 / 大卡 SD 卡座

## 1. 供电

```
充电宝 5V/2A 以上
   │ USB-A → Type-C
   ▼
ESP32 Type-C
   │
   ├── VIN ──► STM32 5V
   ├── VIN ──► E18 ×4（棕线）
   └── VIN ──► SD 模块 +5
GND：全部共地

STM32 3V3 ──► DS3231 VCC、四路 10k 上拉
```

- 不要插 STM32 的 Type-C；不要把 ESP32 的 3V3 与 STM32 的 3V3 并联。

## 2. STM32 引脚分配

| 功能 | 引脚 | 说明 |
| --- | --- | --- |
| 入口探头 A | PB12 | 输入，下降沿 |
| 入口探头 B | PB13 | 输入，下降沿 |
| 队列 50% | PB14 | 输入，电平 + 计时 |
| 队列 100% | PB15 | 输入，电平 + 计时 |
| SD CS | PA4 | 输出，软件片选 |
| SD SCK | PA5 | SPI1 |
| SD MISO | PA6 | SPI1 |
| SD MOSI | PA7 | SPI1 |
| DS3231 SCL | PB6 | I2C1 |
| DS3231 SDA | PB7 | I2C1 |
| ESP32 RX | PA2 | USART2_TX |
| ESP32 TX | PA3 | USART2_RX |
| ST-Link | PA13 / PA14 | SWDIO / SWCLK |
| 供电 | 5V / GND | 来自 ESP32 VIN |
| 外设 3.3V | 3V3 | 供 DS3231 与上拉 |

PB12–PB15、PA4–PA7、PB6–PB7、PA2–PA3 分别对应普通 IO、SPI1、I2C1、USART2，互不冲突。

## 3. 模块接线

### E18-D80NK ×4

| 探头 | 棕 | 蓝 | 黑 |
| --- | --- | --- | --- |
| 入口 A | 5V | GND | PB12 |
| 入口 B | 5V | GND | PB13 |
| 队列 50% | 5V | GND | PB14 |
| 队列 100% | 5V | GND | PB15 |

黑线各加 **10k 上拉到 3.3V**；NPN 常开，低电平有效。

### DS3231

| 模块 | 接到 |
| --- | --- |
| VCC | 3.3V（STM32 3V3） |
| GND | GND |
| SCL | PB6 |
| SDA | PB7 |
| SQW / 32K | 悬空 |

I²C 地址 0x68。电池为 CR2032 时拆掉 R5（充电电阻），或换 LIR2032。

### SD 卡座

| 模块 | 接到 |
| --- | --- |
| GND | GND |
| +3.3 | 悬空 |
| +5 | 5V（ESP32 VIN） |
| CS | PA4 |
| MOSI | PA7 |
| SCK | PA5 |
| MISO | PA6 |
| GND | GND |


### ESP32

| 模块 | 接到 |
| --- | --- |
| Type-C | 充电宝（USB-A 转 Type-C） |
| VIN | 5V 输出给 STM32 / E18 / SD |
| GND | GND |
| GPIO16（U2RXD） | PA2 |
| GPIO17（U2TXD） | PA3 |

用 VIN 输出 5V，不要用 3.3 脚。

### ST-Link

| ST-Link | STM32 |
| --- | --- |
| SWDIO | PA13 |
| SWCLK | PA14 |
| GND | GND |
| 3.3V | 不接 |

## 4. 上电检查

1. 充电宝空载，量 USB 输出 5V。
2. 只接 ESP32，量 VIN 约 4.7V。
3. 接 STM32 的 5V/GND，烧点灯。
4. 逐个接 E18：黑线无遮挡 3.3V、有遮挡 0V。
5. 接 DS3231，I²C 扫描到 0x68。
6. 接 SD，FAT32，挂载成功。
7. 接 ESP32 串口或 Wi-Fi 网页，确认数据。
8. 连续跑 30 分钟，观察 Wi-Fi 发射时是否重启。

## 5. 备注

- E18 必须 5V 供电；不要用 24V 版本。
- 如果 Wi-Fi 峰值时 ESP32 反复重启，换短一点的 USB 线或笔记本 USB 3.0 口。
- STM32 的 Type-C 只供电，不是串口；烧录走 ST-Link。
